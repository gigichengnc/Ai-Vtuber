# Assets for videos

- `backgrounds/`: images (`.jpg`, `.png`, `.webp`) to put behind 朝暮, e.g. her
  bedroom for wake-up videos. The AI writer sees the file names and picks
  fitting ones, so name them clearly (`bedroom.jpg`, `classroom_day.png`).
  Vertical images suit 9:16 videos; any size is cropped to fill the frame.
- `music/`: background music (`.mp3`), played quietly under her voice when a
  script names it in `"music"`.

Only use images and music you're allowed to use (your own, or with a licence
that permits it).
